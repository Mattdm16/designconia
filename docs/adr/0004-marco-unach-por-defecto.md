# Marco UNACH–LIDTS como marco curricular por defecto

El vocabulario y los artefactos (unidad de competencia, subcompetencia, resultado de aprendizaje, programa descriptivo) se toman del modelo UNACH, verificado contra el programa oficial de Fundamentos de matemáticas (MA01, LIDTS). Se parametriza para permitir otros marcos después, pero un lector futuro debe saber por qué el glosario no usa el vocabulario genérico de "unidad didáctica / sesión".

**Considered Options**: Vocabulario genérico agnóstico ("unidad, lección, evaluación") — producía documentos que ningún docente podía entregar tal cual en su institución.
