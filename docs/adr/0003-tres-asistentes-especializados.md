# Tres asistentes curriculares especializados con base común

En vez de un solo chat general, la herramienta usa tres instrucciones de sistema versionadas (planeador de unidad, secuencias por subcompetencia, instrumentos de evaluación) que comparten una base común de marco curricular, vocabulario canónico y formato de salida. Cada una es corta, testeable y versionable por separado; el chat general mezclaba formatos y producía documentos genéricos.
